# 2026-11-03 — Pixel art: a circuit's world drawn as 8/16-bit pixel art

Commit `2bd17f5` on `ccr-5ceb056d-y3evh6`.

## User request

A new circuit of the game's (Costa del Sol) is meant to show off a pixel-art look,
in homage to the 8- and 16-bit racing games. Asked how far to go, the user chose
"low resolution plus palette": the world drawn at a few lines and scaled up sharp,
in a reduced palette with dithering, set per circuit.

## Implementation

- `src/world/scenery.rs`: `Scenery::look`, a new `Look` with `#[serde(default)]`.
  It is `Smooth` (as the options say, the default) or
  `Pixel { lines, levels, dither }` (dither defaults to 0.5). Unknown fields are
  refused, as everywhere else in a circuit's file.
- `src/render_scale.rs`:
  - `PixelLook`, a resource taken from the current circuit each frame
    (`follow_the_look`, in `Update`). `PixelLook::of` keeps the values to their
    limits: 2 lines at least, 2 to 256 shades, dither from 0 to 1.
  - `pixel_size`: the image is `lines` high and as wide as the window's shape, but
    never bigger than the render scale would draw it.
  - `scale_the_world`: with pixel art, the world is drawn into an image of that
    size with a nearest sampler (a new image when the size or the sampling
    changes), without contrast adaptive sharpening, and the smoothed sprite
    is hidden.
  - `show_the_pixel_art`: a `Mesh2d` quad as big as the window with the
    `PixelArt` material, made the first time it is wanted and only where meshes
    exist (not in the tests). It is updated when the image or its uniform
    changes.
  - `pixel.wgsl`: reads the world's pixel with `textureLoad`, so it is never
    blended. It cuts each channel in sRGB to `levels` shades, nudged by a 4×4
    Bayer threshold (bit-interleaved, no lookup table) times `dither`, then
    returns to linear, with Bevy's 2D tonemapping and sRGB output blocks.
- `src/world/detail.rs`: `antialias` treats pixel art as `Antialiasing::Off`, so
  the world's edges stay as hard as its pixels.
- `README.md`: `look` among what a circuit's file says.
