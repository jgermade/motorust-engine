# 2026-11-02: A Check Too Tight for a Busy Runner

## 1. The Circuits Arrive, However Long They Take

### 1.1 Header & Context
- **Date:** 2026-11-02.
- **Task:** a check that failed in a game's CI, not on the engine's.

### 1.2 User Request
> None directly: found in Motorust's CI (its pull request #33, run 171): `circuits_are_prepared_in_the_menus_and_let_go_for_a_race_on`, run on the game's eight circuits, panicked with "the circuits never arrive".

### 1.3 Implementation Details
- The check (`src/world/mod.rs`) waits, updating the app, for every circuit to be prepared in the background and arrive hidden, and gave up after 120 s. On a GitHub runner, with every other test running at once on its few cores (the game's tests took 309 s there, 150 s on a bigger machine), the eight circuits took longer. What it checks is that they arrive, not how soon: the bound is 600 s now, only to stop a test that would wait for ever, and a comment says so.
