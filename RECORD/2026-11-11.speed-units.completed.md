# 2026-11-11 — Speed units: km/h or mph

Branch `claude/youthful-davinci-0c70wu`.

## User request

"In the game options, under the language, we should add speed units (km/h
or mph)." Then: "Go on with the km/h or mph option."

## Implementation

- `src/settings.rs`: `Settings::speed_units` (`SpeedUnits::Kmh`, the default,
  or `Mph`), saved with the rest (a settings file without it reads as
  km/h); `SpeedUnits::label`, `of` (a speed in m/s in these units),
  `on_dial` and `mark`.
- `src/options.rs`: Options > Game, right under the language: "Unidades de
  velocidad" / "Speed units", `<  km/h  >` or `<  mph  >`.
- `src/speedometer.rs`: the same dial in either: 13 marks round it, 0 to
  360 km/h every 30 with the red line from 300, or 0 to 240 mph every 20
  with the red line from 200, so its drawing does not change, only its
  figures; the speed in the middle, the unit under it (and the gear with
  the gears on) and the pointer in the units chosen. The dials drawn are
  kept by size and units, so changing them draws the dial anew.
- Not changed: the curves' HUD of the performance HUD, a tool for tuning
  the steering, still says its speeds in km/h.
